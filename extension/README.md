# Focus Reader

Read one sentence at a time. The page dims, the current sentence is highlighted, and your place is remembered.

## Install (Chrome, Edge, Brave)

1. Unzip this folder.
2. Open `chrome://extensions` and turn on **Developer mode** (top right).
3. Click **Load unpacked** and pick the `focus-reader` folder.
4. Pin the extension to the toolbar.

## Use

Click the toolbar icon (or press **Alt+Shift+R**):

- **On a web page**: the page dims and one sentence is highlighted.
- **On a PDF tab**: the PDF opens in the built-in reader in a new tab.
- **On a new/blank tab**: the built-in reader opens. Drop in a PDF, Word (.docx), PowerPoint (.pptx), EPUB, Markdown, HTML or text file, paste text, or enter a link.

The bar at the bottom has **Speed** (0.25× to 3×) and **Voice** (every voice installed on your device, grouped by language and accent).

| Key | Action |
| --- | --- |
| → / ↓ / Space / J | Next sentence |
| ← / ↑ / K | Previous sentence |
| Click a sentence | Jump to it |
| S | Read aloud, auto-advancing |
| Esc | Exit |

Your position on each page is saved, so reopening the reader resumes where you stopped.

## Limits

- Scanned PDFs (images of pages with no selectable text) are not supported yet.
- PDFs saved on your computer: drop the file into the reader, or enable "Allow access to file URLs" for the extension.
- Old `.doc` / `.ppt` / `.rtf` files: save as PDF or `.docx` first.
- Voices come from your operating system and browser, so the list differs by device.
